## 🤖 Featured Projects

### 1. BlueROV2 LED-Based Visual Tracking & Perception

Implements LED-based target detection, geometric tracking, relative distance estimation, and UDP-based observation streaming. Includes experimental performance analysis, trajectory visualization, and interactive 3D mission replay.

**Python · OpenCV · Computer Vision · Visual Tracking · Unity · Plotly**

### 2. robotsim — C++ Robot Navigation & Reinforcement Learning

A C++17 mobile robot simulation environment with differential-drive dynamics, simulated LiDAR, collision detection, and a Gymnasium-compatible Python interface.

Includes a PPO reinforcement learning agent, rule-based navigation baseline, quantitative evaluation, and reproducible training experiments.

**C++17 · Python · Reinforcement Learning · PPO · Gymnasium · Robot Navigation**

[View project & results →](https://github.com/eranaydogan/robotsim)

Vision-based robot control pipeline that converts perception observations into MAVLink commands for BlueROV2 / ArduSub simulation.

**Python · MAVLink · ArduSub · Gazebo · UDP · Robot Control**

[View project →](https://github.com/eranaydogan/bluerov2-led-control)
